# GodMian

GodMian คือเว็บไซต์ของแฟนเกมสำหรับชมภาพตัวอย่างและดาวน์โหลดม็อด Heroes of Newerth ผู้ชมค้นหาผลงานตามชื่อ กรองตามหมวด เรียงตามวันที่อัปเดต และเปิดแกลเลอรีของแต่ละรายการได้ เว็บไซต์เก็บเนื้อหาไว้ใน JSON และให้ Google Drive จัดส่งไฟล์ม็อด

## เปิดเว็บไซต์และระบบจัดการม็อดบนเครื่อง

1. **วิธีที่ง่ายที่สุด (แนะนำ):** ดับเบิลคลิกไฟล์ **`Admin_Tool.bat`** ในโฟลเดอร์โปรเจกต์
   - ระบบจะเปิดเว็บเซิร์ฟเวอร์ในเครื่องพร้อมหน้าจัดการม็อดที่ `http://127.0.0.1:8765/admin` (สร้าง/แก้ไขม็อด, เปิด/ปิดการแสดงผลฮีโร่ในคลิกเดียว, แปลงรูปเป็น WebP sRGB, ซิงก์คลิปสกิลจาก Google Drive)
   - ดูหน้าเว็บจริงตัวอย่างได้ที่ `http://127.0.0.1:8765/`
2. **อัปเดตเวอร์ชันม็อดและดึงคลิปสกิลอัตโนมัติ:** ดับเบิลคลิกไฟล์ **`Update_Mod.bat`** (หรือรัน `python scripts/update-mod.py --auto`)
3. **เปิดเว็บเซิร์ฟเวอร์สแตติกด้วย Python มาตรฐาน:**

   ```sh
   python -m http.server 8000 --bind 127.0.0.1
   ```

   เปิด [GodMian บนเครื่อง](http://127.0.0.1:8000/) เลือก **Explore Mods** หรือกด `/` เพื่อค้นหา เมื่อขยายภาพในแกลเลอรี ใช้ปุ่มลูกศรซ้าย–ขวาเพื่อเปลี่ยนภาพ และกด `Esc` เพื่อปิด

## Build และเผยแพร่

โปรเจกต์นี้ใช้ HTML, CSS และ JavaScript modules ที่พร้อมเผยแพร่จากโฟลเดอร์ต้นฉบับได้ทันที จึงข้ามการติดตั้งแพ็กเกจและขั้นตอน build ได้ เว็บไซต์ทำงานในเบราว์เซอร์ โดยมี Google Drive เป็นปลายทางดาวน์โหลดไฟล์ `.honmod`

| สิ่งที่นำไปเผยแพร่ | หน้าที่ |
| --- | --- |
| `index.html`, `404.html`, `.nojekyll` | จุดเข้าเว็บไซต์ หน้าสำหรับ URL ที่หาไม่พบ และการเสิร์ฟไฟล์โดยตรงบน GitHub Pages |
| `styles/`, `js/` | หน้าตา ธีมสีม่วงนีออน (`--pop`) การนำทาง แกลเลอรี พรีวิวคลิปสกิล ระบบ Analytics และตัวอ่านข้อมูล |
| `data/mods.json` | สารบัญ slug ตามลำดับการแสดงผล (ใส่ `-` หน้าชื่อเพื่อซ่อนชั่วคราวได้) |
| `data/characters/<slug>.json` | ข้อมูลตัวละคร สถานะเปิด/ปิด (`enabled`), รูปปก, สกิล (`Q`, `W`, `E`, `R`), คลิปวิดีโอ และลิงก์ดาวน์โหลด |
| `assets/` | ภาพ WebP, คลิปวิดีโอสกิล MP4 (`assets/video/`), โลโก้ GodMian และชุดไอคอน SVG |

สำหรับ GitHub Pages ให้เผยแพร่จากโฟลเดอร์รากของ branch `main` ดูขั้นตอนใน [คู่มือ Deploy](DEPLOYMENT.md)

## เพิ่มและจัดการผลงานจริง

สามารถเพิ่มหรือแก้ไขม็อดผ่านหน้าเว็บ **`Admin_Tool.bat`** (`http://127.0.0.1:8765/admin`) หรือคัดลอก `data/character-template.json` เป็น `data/characters/<slug>.json` แล้วเพิ่ม slug ลงใน `data/mods.json`:

- ตั้ง `"enabled": true` เพื่อแสดงฮีโร่บนเว็บ หรือ `"enabled": false` (หรือกดปุ่ม `🚫 ปิด` ในหน้า Admin) เพื่อซ่อนฮีโร่ไว้ก่อนโดยไม่ต้องลบข้อมูล
- ตั้ง `"featured": true` เพื่อแสดงในสไลด์ด้านบนสุด (Hero Spotlight) และหมวด **Featured mods.**
- เมื่อพร้อมแจกไฟล์ `.honmod` ให้อัปโหลดขึ้น Google Drive ตั้งสิทธิ์ **Anyone with the link · Viewer** แล้ววางลิงก์แชร์ใน `downloadUrl` ดูคำอธิบายทุกฟิลด์ได้ใน [คู่มือเพิ่มม็อด](HOW_TO_ADD_MODS.md)

## แผนพัฒนาในอนาคต (Future Roadmap / To-Do List)

รายการฟีเจอร์ที่วางแผนจะทำเพิ่มเติมในระยะถัดไป:

- [ ] **ระบบดึงยอดผู้ติดตาม TikTok มาแสดงบนเว็บเพื่อปลดล็อกแจกสกิน (TikTok Follower Milestone Unlock):**
  - แสดงหลอดความคืบหน้าจำนวนผู้ติดตามช่อง TikTok เทียบกับเป้าหมาย (เช่น `850 / 1,000 ผู้ติดตาม`)
  - ตั้งค่าเป้าหมายผู้ติดตามรายม็อดในหน้า Admin ได้ (เช่น `tiktokGoal: 1000`) ถ้ายอดยังไม่ถึงเป้าจะแสดงปุ่มชวนไปกดติดตาม TikTok แทนปุ่มดาวน์โหลด และเมื่อยอดผู้ติดตามถึงเป้าแล้ว ปุ่ม **Download mod** จะปลดล็อกให้ดาวน์โหลดอัตโนมัติ
  - เพิ่มปุ่มดึงยอดผู้ติดตาม TikTok ล่าสุดใน `Admin_Tool.bat` และ/หรือตั้ง GitHub Actions เช็กยอดอัตโนมัติ
- [ ] **ระบบดึงยอดดาวน์โหลดม็อด (`mod_download`) จาก Google Analytics 4 มาแสดงบนหน้าเว็บ:**
  - เชื่อมต่อ GA4 Data API ผ่าน GitHub Actions (เก็บ Service Account Key ใน GitHub Secrets เพื่อความปลอดภัย) เพื่อซิงก์ยอดดาวน์โหลดจริงลง `data/stats.json` แล้วนำมาแสดงบนการ์ดม็อดและหน้ารายละเอียด
