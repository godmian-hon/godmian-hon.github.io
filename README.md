# GodMian

GodMian คือเว็บไซต์ของแฟนเกมสำหรับชมภาพตัวอย่างและดาวน์โหลดม็อด Heroes of Newerth ผู้ชมค้นหาผลงานตามชื่อ กรองตามหมวด เรียงตามวันที่อัปเดต และเปิดแกลเลอรีของแต่ละรายการได้ เว็บไซต์เก็บเนื้อหาไว้ใน JSON และให้ Google Drive จัดส่งไฟล์ม็อด

## เปิดเว็บไซต์บนเครื่อง

1. ดาวน์โหลดหรือโคลนโปรเจกต์ แล้วเปิด Terminal ในโฟลเดอร์ที่มี `index.html`
2. หากมี Python 3 ให้เริ่มเว็บเซิร์ฟเวอร์สำหรับดูตัวอย่างด้วยคำสั่งด้านล่าง บน Windows ที่ใช้ Python Launcher เปลี่ยน `python` เป็น `py -3` ได้

   ```sh
   python -m http.server 8000 --bind 127.0.0.1
   ```

3. เปิด [GodMian บนเครื่อง](http://127.0.0.1:8000/) เลือก **Explore Mods** หรือกด `/` เพื่อค้นหา เมื่อขยายภาพในแกลเลอรี ใช้ปุ่มลูกศรซ้าย–ขวาเพื่อเปลี่ยนภาพ และกด `Esc` เพื่อปิด
4. หลังแก้ไฟล์ ให้รีเฟรชเบราว์เซอร์ กด `Ctrl+C` ใน Terminal เมื่อเลิกดูตัวอย่าง

เปิดผ่าน HTTP เพื่อให้เบราว์เซอร์อ่าน JSON และ JavaScript modules ได้ ใช้เว็บเซิร์ฟเวอร์สแตติกตัวอื่นแทน Python ได้เช่นกัน

บนเครื่อง Windows ที่ใช้สร้างโปรเจกต์นี้ สามารถใช้ Python ที่มากับ Codex ได้โดยเปิด PowerShell ในโฟลเดอร์โปรเจกต์แล้วรัน

```powershell
& "$env:USERPROFILE\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe" -m http.server 8000 --bind 127.0.0.1
```

## Build และเผยแพร่

โปรเจกต์นี้ใช้ HTML, CSS และ JavaScript modules ที่พร้อมเผยแพร่จากโฟลเดอร์ต้นฉบับได้ทันที จึงข้ามการติดตั้งแพ็กเกจและขั้นตอน build ได้ เว็บไซต์ทำงานในเบราว์เซอร์ โดยมี Google Drive เป็นปลายทางดาวน์โหลด

| สิ่งที่นำไปเผยแพร่ | หน้าที่ |
| --- | --- |
| `index.html`, `404.html`, `.nojekyll` | จุดเข้าเว็บไซต์ หน้าสำหรับ URL ที่หาไม่พบ และการเสิร์ฟไฟล์โดยตรงบน GitHub Pages |
| `styles/`, `js/` | หน้าตา การนำทาง แกลเลอรี และตัวอ่านข้อมูล |
| `data/mods.json` | สารบัญ slug ตามลำดับการแสดง |
| `data/characters/<slug>.json` | ข้อมูล รูป วิดีโอ สกิล และลิงก์ดาวน์โหลดของแต่ละตัวละคร |
| `assets/` | ภาพ WebP แบรนด์ ไอคอน และภาพสำรอง |

สำหรับ GitHub Pages ให้เผยแพร่จากโฟลเดอร์รากของ branch ที่เก็บไฟล์เหล่านี้ ดูขั้นตอนสร้าง repository และทดสอบเว็บหลังเผยแพร่ใน [คู่มือ Deploy](DEPLOYMENT.md)

## เพิ่มผลงานจริง

เพิ่มภาพลงใน `assets/art/` และคัดลอก `data/character-template.json` เป็น `data/characters/<slug>.json` แล้วเพิ่ม slug ลงใน `data/mods.json` ตั้งชื่อ หมวดและเวอร์ชันตามไฟล์จริง ตั้ง `featured` เป็น `true` เมื่อต้องการแนะนำผลงาน เมื่อพร้อมแจกไฟล์ ให้อัปโหลดขึ้น Google Drive ตั้งสิทธิ์ **Anyone with the link · Viewer** แล้วบันทึกลิงก์แชร์ใน `downloadUrl` ดูคำอธิบายทุกฟิลด์และตัวอย่างได้ใน [คู่มือเพิ่มม็อด](HOW_TO_ADD_MODS.md)

## ผลงานตัวอย่างและที่มาของภาพ

ข้อมูลเริ่มต้นสี่รายการเป็น **ภาพคอนเซปต์** ภาพสร้างขึ้นสำหรับเว็บนี้ด้วย ImageGen ในตัว ชุดตัวอย่างยังไม่มีแพ็กเกจม็อดให้ติดตั้ง จึงแสดง **Unavailable** ในหน้ารายละเอียด ผู้ดูแลแทนที่ข้อมูลและภาพด้วยผลงานที่พร้อมเผยแพร่ได้

| ชุดภาพใน `assets/art/` | แนวทางภาพตัวอย่าง |
| --- | --- |
| `frostbound*` · Frostbound Warden | ผู้พิทักษ์ในเกราะเหล็กสีเข้ม สวมมงกุฎหนามน้ำแข็งกลางพายุแสงสีฟ้า เน้นโครงร่างเกราะและผิวโลหะ |
| `emberfall*` · Emberfall Behemoth | อสูรเขาโค้งกลางภูเขาไฟ แสงลาวาส่องจากรอยแยกในเกราะหินบะซอลต์ |
| `veilstrider*` · Veilstrider | เอลฟ์ผมขาวในซากวิหารใต้แสงจันทร์สีม่วง ภาพรายละเอียดเน้นถุงมือโลหะและคมดาบพลังงานรูปเสี้ยวจันทร์ |
| `verdant-crossing*` · Verdant Crossing | สะพานหินเหนือธารสีมรกตใต้เรือนยอดไม้ อีกมุมมองตามทางเดินไปยังซุ้มประตูที่ปกคลุมด้วยเถาวัลย์ |

GodMian เป็นโปรเจกต์อิสระที่จัดทำโดยแฟนเกม ผู้พัฒนา Heroes of Newerth ไม่มีส่วนเกี่ยวข้องกับเว็บไซต์
